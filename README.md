# 肥鱼养成记 2.3.2

一个全群共养宠物的 AstrBot 插件。鱼友一起照料大肥鱼、玩小游戏、参加突发事件，把小鱼养大，再留下每一轮的毕业回忆。

## 开始养鱼

在群里发送 `养鱼` 打开鱼塘面板。面板会显示饱腹、心情、洁净、活力、体重、成长进度和个人道具。默认使用平台昵称；没有收到昵称时，机器人会引导登记，也可以用 `昵称 名字` 自定义称呼。

按钮会按鱼的状态和当前玩法动态变化，手机端使用三列布局。正在冷却的日常互动会暂时收起，文案会说明刚才陪大肥鱼做过什么，并把当前可用的互动留在按钮上。称重、排行、档案和鱼塘面板收在“更多”里；小游戏结果优先保留当前玩法入口。

## 日常养成

- `投喂` 和 `加餐` 消耗白饭，补充饱腹；`逗鱼` 提升心情；`净水` 改善洁净度。
- `玩耍` 开一局套圈，会消耗活力；`Token陪玩` 消耗 1 枚 Token，使用随机主题并提供额外成长机会。
- `签到` 获得白饭和游历机会，连续签到达到阶段时还能获得额外奖励；`钓鱼` 可随机钓到白饭或 Token。
- `许愿` 消耗白饭获得增益。鱼友也可以在群里 @机器人，或称呼“大肥鱼、肥鱼、鲸鱼、小鲸鱼、小肥鱼”，有概率获得白饭或 Token。群聊奖励有个人冷却和每日上限。

属性会随时间变化。照料动作按鱼友分别计算冷却；面板只展示当前可进行的日常互动。鱼塘会记录共同进度、每日心愿和每周委托。

## 突发救援

照料过程中可能触发救援事件，包括水草缠绕、大泡泡困住、玩具卡进石缝、风筝线缠尾、旧渔网卡鳍、贝壳卡住、陶罐困住和滚石压鳍。每次需要 2–3 位鱼友参与；参与者各自只能接力一次。

大肥鱼脱困前，其他养成操作和小游戏会暂停，消息按钮只保留“救援”，方便群友接力。救援成功后发放奖励并恢复正常玩法；若事件超时仍无人完成，大肥鱼会受挫，事件结束后可以继续互动。

## 小游戏与游历

首次使用小游戏前，先点一次 `小游戏` 打开玩法入口；每轮鱼塘都需要重新打开。入口包括：

- `猜鱼`：猜大肥鱼心里的数字，猜中或用完机会都有对应结果。
- `寻宝`：三位不同鱼友依次探路、搬石、开箱，合力完成接力。
- `游历`：使用签到获得的机会，选择路线经历 3–5 段旅程，带回白饭或 Token。途中有机会遇到 Claude、GLM、Kimi、Gemini、Grok、GPT、千问和豆包，获得各自的陪伴与奖励；也有极低概率遇见梁帝，每位鱼友仅能触发一次。
- `奇遇`：每人每天一次，由发起者选择帮忙、探索或返回，可能带回故事、建设材料和纪念物。
- `运动会`：每周参加一次，选择项目和训练策略；也可以每天为鱼友助威。

`心愿` 和 `每周委托` 会随着正常照料推进；完成后可获得建设材料。`建设` 用材料装饰公共鱼塘。`性格` 记录本轮养成出来的性格，不提供额外属性加成。

## 日记、毕业与收藏

当天完成有效互动后，结果菜单会解锁 `大肥鱼日记`。如果套圈、猜鱼、游历、奇遇、寻宝或救援还在进行中，日记会等流程结束后再出现。

鱼达到最后成长阶段、体重至少 80 且心情至少 60 时可以 `出栏`。毕业或离别会留下合影；`纪念册` 保留最近 20 轮，`纪念物` 和 `周报` 可查看个人收藏及最近八期委托记录。

换鱼后，白饭、Token、绝版海苔、材料、装饰、收藏和纪念册会保留；亲密度与性格重新养成。海苔是旧版本留下的绝版道具，新版本不再产出或消耗。

## 安装与配置

1. 将仓库放到 AstrBot 的 `data/plugins/astrbot_plugin_dafeiyu` 目录。
2. 在插件管理中加载或重载，依赖为 Pillow。
3. 在 QQ 群里发送 `养鱼`。

升级时覆盖插件文件并保留存档。默认存档目录为 `data/plugin_data/astrbot_plugin_dafeiyu`；如设置了 `data_dir`，则以配置为准。

| 配置项 | 说明 |
| --- | --- |
| `output_mode` | `markdown` 显示卡片和按钮；也可选 `text` |
| `send_image` | 是否发送鱼图和纪念图 |
| `difficulty` | `休闲`、`标准`、`硬核`，调整属性衰减速度 |
| `data_dir` | 自定义存档目录，留空使用默认目录 |
| `sticker_enabled` | 是否启用贴图源 |

QQ 官方平台支持直接点击按钮。OneBot v11 无法处理按钮回调时，插件会显示对应的文字指令；也支持 `/养鱼` 和 `#养鱼`。按钮或文字排版异常时，可切换 `output_mode` 为 `text`。

图片优先使用贴图源，其次是存档目录中的 `fish_imgs/` 自定义图片，最后使用内置鱼图。装饰建成后会合成鱼塘场景，纪念册使用独立纪念图。
