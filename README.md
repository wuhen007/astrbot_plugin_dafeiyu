# 肥鱼养成记（astrbot_plugin_dafeiyu）

以"大肥鱼"为主题的 **QQ 群共养宠物游戏**，作为 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 插件 + 官方 QQ 机器人运行：
全群共养一条鱼，投喂、逗鱼、净水、套圈小游戏把它养成「大肥鱼」，然后风光**出栏**毕业结算（S/A/B/C 评级），再养一条开启新的轮回。

> 本项目玩法与文案为**原创设计**（详见文末"与参考玩法的差异"），仅借鉴"群养宠物 + 属性衰减 + 按钮交互"这一体验骨架，未使用任何现有游戏的素材、名称、界面、文案与数值。

## 玩法

**目标**：把鱼养成「大肥鱼」（体重 ≥80 且心情 ≥60 且到达终阶），发 `出栏` 举行出栏大典。

**核心循环**（每次交互一条消息，轻快）：

```
登记名号 → 看面板 → 投喂/逗鱼/净水/玩耍 补状态赚经验 → 升级进阶 → 属性随现实时间衰减 → 达标出栏 → 重开
```

**名号登记**：QQ 官方 bot 拿不到群昵称，所以首次照料时会引导发送 `养鱼 昵称 名字` 登记（≤12 字，`昵称 新名字` 随时改名）；排行、档案、毕业鸣谢都用它。平台自带真实昵称时自动采用、无需登记。

**轻玩法（v1.2.0，全部按钮可点）**：
- 📅 **每日打卡**：每自然日一次；连续 ≥3 天海苔片+2、≥7 天 +3（断签归 1），钱包跨鱼有效
- 🎣 **一键钓鱼**：30 分钟冷却；40% 海苔片+1 / 25% 心情+8 / 15% 体重+2 / 12% 水草安慰奖（心情+2）/ 8% **宝箱**（海苔片+3）
- 🛟 **求援事件**：照料时 10% 概率突发（被水草缠住/被泡泡困住/玩具卡石缝），10 分钟内凑齐 2 位鱼友点「🛟 救援」→ 参与者各得海苔片+2、鱼心情+10；没人救过期 → 鱼心情-5
- 🙏 **许愿池**：花海苔片×2 随机换 心情+20 / 活力+40 / 体重+3 / 返还 1 片

**指令与按钮**（等价，按钮是原生 QQ 按钮，点击即触发）：

| 指令 | 效果 | 冷却 |
|---|---|---|
| 养鱼 | 面板：状态条 + 成长进度 + 实时鱼图 | – |
| 投喂 | 饱腹 +22 · 体重 +2~4 · 经验 +8 | 45min；饱腹 ≥92 时硬喂会"撑到"（体重 -1 心情 -6） |
| 加餐 | 花 1 海苔片：饱腹 +15 心情 +8（无撑到风险） | 15min |
| 逗鱼 | 心情 +6 · 经验 +6 · 亲密 +1 | 15min |
| 净水 | 洁净 +35 · 经验 +5 | 2h |
| 玩耍 | **套圈小游戏**：猜鱼粮藏在哪个泡泡（1/2/3），猜中体重 +3 心情 +8，猜错心情 +3；需活力 ≥20，开局即扣 | 1h |
| 称重 | 看体重/成长进度与养成建议 | 10min |
| 签到 | 每日打卡，连续 ≥3/≥7 天追加海苔片 | 每日一次 |
| 钓鱼 | 五档随机奖励（40% 海苔片 / 25% 心情+8 / 15% 体重+2 / 12% 水草 / 8% 宝箱） | 30min |
| 救援 | 参与求援事件（凑齐 2 人全员有奖） | 事件期间一次 |
| 许愿 | 花海苔片×2 随机换增益 | – |
| 排行 | 群内亲密 Top5（最疼鱼的人） | – |
| 档案 | 出栏图鉴 | – |
| 出栏 | 达标后毕业结算 | – |
| 再养一条 | 结算后重开 | – |

**结束与结算**

- **胜利·出栏大典**：按 体重 40% + 心情 25% + 洁净 15% + 亲密 20% 评分 → S(≥85)/A(≥70)/B(≥55)/C 评级；第 1 名贡献者获全额海苔片奖励（S:20/A:12/B:8/C:4），第 2、3 名半额；鱼入群图鉴。
- **失败·离家出走**：饱腹归零持续 36h、或心情归零持续 72h → 鱼不辞而别，强制 C 级遗憾结算。
- **重开**：结算后发 `再养一条`；海苔片钱包、图鉴、累计次数保留，亲密随新鱼重置。

**难度曲线（循序渐进）**

- 自然衰减随阶段加速：×1.0 → ×1.85（Lv1→Lv6）；鱼塘等级每级减免 4%（全群每 200 次互动升 1 级，上限 5 级）
- 同一动作连用主收益 ×0.75ⁿ（逼你换花样）
- 洁净 <30：增重减半，且套圈猜中也会捞到"泥球"——先净水再玩耍
- 休闲游玩约 2~3 天毕业一轮（`sim.py --auto` 演示为 4.1 天，因自动玩家非最优）

**视觉表现**：实时 PIL 画鱼——体型随体重、表情随心情（笑/平/哭+汗滴）、水色随洁净（浑浊+漂垃圾）、气泡随心情、冲刺线随活力、饿了冒"？"思考泡、毕业戴礼帽+彩带、离家出走画"…游走了…"木牌。

## 部署

1. 把本仓库克隆（或下载解压）到 AstrBot 的插件目录：`data/plugins/astrbot_plugin_dafeiyu`
2. WebUI → 插件管理 → 加载/重载本插件；依赖 `requirements.txt`（Pillow）会自动安装（或手动 `pip install Pillow`）
3. 指令：`@机器人 养鱼` 与 `@机器人 /养鱼` **都能用**（投喂/玩耍 等子指令同样支持斜杠写法）
4. QQ 官方 bot（`qqofficial` 平台）Markdown/按钮：**群聊与单聊的自定义 Markdown 和消息按钮已于 2026-04 全量开放，无需申请**（[官方文档](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/type/markdown.html)）；仅频道场景需内邀
   - 默认 `output_mode=markdown`；若实际显示成带 `**` 的纯文本，是 AstrBot 适配器侧未走 md：确认 AstrBot 版本较新（含 `Button/ActionRow`），或平台配置里 `use_markdown` 开关打开
   - md 内容已按 QQ 支持的语法子集渲染（#/## 标题、**加粗**、空行分段；不用表格/代码块）
   - 原生按钮（点击回调）需要 AstrBot v4+（内置 `Button/ActionRow/ButtonInteraction`）；旧版自动退化为文字指令
5. **鱼形象来源（三级优先）**：
   - ① **fisharchive.cc 贴图源**（默认开启）：按指令/状态自动挑语义相近的贴图（投喂→吃饭系、逗鱼→开心系、未登记→卖萌系……），索引与图片本地缓存；素材为"蓝色大肥鱼"系贴图，[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 授权，来源于 [fisharchive.cc](https://fisharchive.cc/)（署名保留于本页）
   - ② 存档目录下 `fish_imgs/` 自定义贴图（png/jpg/gif/webp，随机取一张）——想完全用自己的图就放这里
   - ③ 内置 PIL 画鱼（无网络/无素材时兜底）

## 配置项（WebUI 可改）

| 键 | 默认 | 说明 |
|---|---|---|
| output_mode | markdown | markdown=卡片+按钮（md/按钮已全量开放）；text=纯文本排版（保守降级） |
| send_image | true | 随消息发送鱼图：fish_imgs/ 自定义优先，否则实时画鱼 |
| difficulty | 标准 | 衰减速度：休闲 0.7x / 标准 1.0x / 硬核 1.4x |
| data_dir | （空） | 存档目录，留空自动 `data/plugin_data/astrbot_plugin_dafeiyu` |

## 关键参数速查（`game/config.py`，改玩法只动它）

- 衰减/小时：饱腹 2.5 · 心情 1.5 · 洁净 1.0 · 活力回复 6
- 六阶经验阈值：50/110/200/320/500（鱼籽→鱼苗→豆丁鱼→圆滚鱼→肥壮鱼→大肥鱼）
- 动作冷却：投喂 45min · 加餐 15min · 逗鱼 15min · 净水 2h · 玩耍 1h · 称重 10min
- 撑到阈值 92；收益递减 ×0.75ⁿ（下限 0.3）；脏水阈值 30（增重 ×0.5）
- 出栏：体重 ≥80 · 心情 ≥60；评级线 85/70/55；奖励 20/12/8/4
- 离家出走：饱腹归零宽限 36h · 心情归零宽限 72h
- 鱼塘：每 200 次群互动升 1 级（上限 5），每级衰减 -4%；海苔片：新鱼友 3 条 · 每日互动补贴 1 条

## 本地开发（不需要 QQ/AstrBot）

```bash
pip install -r requirements.txt   # Pillow
python -m pytest tests -q         # 全量测试（引擎/渲染/画鱼/插件接线/端到端）
python sim.py                     # 终端交互游玩（`等 5` 快进 5 小时）
python sim.py --auto              # 自动演示：鱼籽 → 出栏大典（胜利结局）
python sim.py --auto-neglect      # 自动演示：无人照顾 → 离家出走（失败结局）
python sim.py --auto --md         # 用 Markdown 卡片渲染预览 QQ 效果
```

## 与参考玩法的差异（原创声明）

参考对象是群里一款"官方 bot 养鱼"文字游戏，本插件**仅借鉴**其体验骨架（全群共养、属性随时间衰减、动作按钮矩阵、群贡献展示），以下均为原创改动：

1. **属性体系不同**：饱腹/心情/洁净/活力 + 隐藏体重·亲密，砍掉了"水分"类属性，新增"活力"作为玩耍资源（先喂后玩），所有数值全新
2. **动作名与文案全新**：投喂/加餐/逗鱼/净水/玩耍/称重，配原创随机小剧场文案；无"逛街/日记/群养成"等原版动作
3. **新增策略小游戏**：三壳套圈——猜中与否取决于选择而非纯概率，且与净水联动（脏水会捞到泥球），参考玩法无此机制
4. **明确的游戏目标与结束**：出栏大典（S/A/B/C 结算+贡献者奖励）与离家出走（失败结局）+ 图鉴 + `再养一条` 重开，形成"一局有始有终"的循环；参考玩法为无终点的纯养成
5. **难度曲线系统化**：阶段衰减倍率、连用收益递减、脏水惩罚、鱼塘等级减免——均为原创数值设计
6. **无 AI 对话产出/私聊收藏等原版群养成周边**，代之以更简单的贡献排行 + 全群互动进度（鱼塘等级）
