# 肥鱼养成记 2.1.0

一个全群共养宠物的 AstrBot 插件。一起喂鱼、陪它玩，把小鱼养成大肥鱼，再留下毕业合影，开始下一轮。

## 2.0 重构

这次把养成、小游戏、共同建设和毕业回忆串了起来。加了猜鱼、寻宝、奇遇、心愿、运动会和每周委托；鱼会形成自己的性格，鱼塘装饰和个人收藏也能一直留下来。原有存档可以继续用。

## 怎么玩

发送 `养鱼` 打开面板，大部分操作都能直接点按钮，也支持 `/养鱼` 和 `#养鱼`。

| 指令 | 用途 |
| --- | --- |
| 养鱼 | 查看鱼的状态和成长进度 |
| 投喂 / 加餐 / 逗鱼 / 净水 | 日常照料，投喂和加餐消耗白饭 |
| 玩耍 / 称重 | 玩套圈、查看体重 |
| 签到 / 钓鱼 / 许愿 / 救援 | 日常奖励和群内互动 |
| 小游戏 | 打开玩法菜单 |
| 猜鱼 | 猜它心里的数字，三次机会 |
| 寻宝 | 三位鱼友接力探路、搬石、开箱 |
| 奇遇 | 选择帮忙或探索，发现故事和纪念物 |
| 心愿 / 委托 | 查看今日目标和每周共同任务 |
| 建设 | 捐材料共建水草角、贝壳小屋和月亮灯 |
| 性格 | 查看这一轮养出来的性格 |
| 运动会 | 选择项目和训练策略参赛，也可以助威 |
| 纪念物 / 周报 | 查看个人收藏和最近八期委托记录 |
| 排行 / 档案 | 查看贡献排行和历代鱼的记录 |
| 出栏 | 达标后毕业结算 |
| 纪念册 / 合影 | 翻看最近20轮毕业或离别留下的回忆 |
| 再养一条 | 结算后开始下一轮 |
| 昵称 名字 | 自定义自己的名号 |

鱼会随时间变饿、变闷、水也会变脏，记得常回来看看。养到最后阶段、体重达到80且心情不低于60，就能出栏。

奇遇每人每天一次，只有发起者能选择路线。每日心愿和每周委托会随着正常照料自动推进，完成可获得建设材料。委托目标按近期实际参与人数确定，每人每类每天最多计两次。

日常动作冷却按鱼友分别计算，群友可以错峰照料；同一动作的次数与奖励仍按游戏规则结算。鱼塘纪念册保留最近20期。

运动会每人每周参加一次，换鱼不会重置机会；助威每天一次。日常与周常都按服务器本地时间刷新。

性格由本轮照料习惯形成。装饰和性格不提供额外属性加成。海苔是旧版本留下的绝版道具：已有库存会保留，但新版本不再产出或消耗。换鱼后，白饭、Token、海苔、材料、装饰、收藏和纪念册保留，亲密与性格重新养成。

默认采用平台昵称，未收到昵称时会引导登记，也可以随时设置自己的名号。

## 安装与升级

1. 将仓库放到 AstrBot 的 `data/plugins/astrbot_plugin_dafeiyu` 目录。
2. 在插件管理中加载或重载，依赖为 Pillow。
3. 在 QQ 群里发送 `@机器人 养鱼`。

升级时覆盖插件文件，保留原有存档。默认存档在 `data/plugin_data/astrbot_plugin_dafeiyu`，设置过 `data_dir` 的以配置为准。

## 配置

| 配置项 | 说明 |
| --- | --- |
| output_mode | 默认 markdown，显示卡片和按钮；也可选 text |
| send_image | 是否发送鱼图和纪念图 |
| difficulty | 休闲、标准、硬核，调整属性衰减速度 |
| data_dir | 自定义存档目录，留空使用默认目录 |
| sticker_enabled | 是否启用贴图源 |

按钮需要 AstrBot 的按钮组件支持；无法显示时可以直接发送文字指令。文字排版异常时可切换为 text 模式。

图片优先使用贴图源，其次是存档目录下 `fish_imgs/` 的自定义图片，最后使用内置画鱼。装饰建成后会合成鱼塘场景，纪念册使用独立的纪念图。

## 兼容性说明

为绕开回调注册表的并发锁，插件对 QQ 官方适配器的 `_parse_keyboard` 做了兼容补丁。本插件的指令按钮在本地构建；遇到其他插件的回调按钮会交回原实现。这里依赖 AstrBot 内部接口，升级后可能需要调整，后续会优先改用官方接口。

文字卡片会设置 `reply_keep_format` 标记，让 dafeiyu_suite 的单行回复整形保留换行。小游戏继续使用文字和按钮，无需生成说明图片。
